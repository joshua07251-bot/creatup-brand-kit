이 기기의 작업 현황

아직 시작한 편집기가 없어요.

편집기 4종

필요한 것부터 열어 바로 시작하세요. 모두 무료, 로그인 없이 브라우저에서 작동합니다.

추천 사용 순서

정해진 순서는 없지만, 처음이라면 이렇게 진행하면 자연스럽습니다.

  1. STEP 01

    나를 소개하기

    소개 홈페이지로 이름·사진·서비스·연락처를 한 페이지에 정리합니다.

  2. STEP 02

    제안 만들기

    판매 상세페이지로 상품·강의·서비스를 구매 흐름에 맞게 설명합니다.

  3. STEP 03

    작업 보여주기

    포트폴리오에 실제 작업과 내가 맡은 역할을 근거와 함께 모읍니다.

  4. STEP 04

    깔끔하게 전달하기

    납품 안내서로 결과물·확인 방법·지원 범위를 문서로 남깁니다.

작업 보관

편집 내용은 이 기기의 브라우저에만 저장됩니다. 기기를 바꾸거나 기록을 지우기 전에 백업하세요.

전체 백업 · 복원

네 편집기의 자동 저장 내용을 파일 하나로 내려받고, 다른 기기에서 그대로 복원합니다.

편집기별 ‘편집본 백업’ JSON과는 다른 묶음 파일입니다. 사진이 많으면 파일이 커질 수 있어요.

편집기별 저장 상태

      자주 묻는 질문

      편집한 내용은 어디에 저장되나요?

      입력한 문구와 사진은 서버로 전송되지 않고, 지금 쓰는 기기의 브라우저에만 자동 저장됩니다. 다른 기기나 다른 브라우저에서는 보이지 않으니, 각 편집기의 ‘편집본 백업’ 또는 이 페이지의 ‘전체 백업’으로 보관하세요.

      만든 페이지는 어떻게 인터넷에 공개하나요?

      편집기에서 저장한 index.html 파일을 GitHub Pages나 Netlify 같은 정적 호스팅에 올리면 주소가 생깁니다. 파일 저장만으로는 공개되지 않습니다. GitHub Pages 안내 ↗ · Netlify 수동 배포 안내 ↗

      사진을 많이 넣었더니 자동 저장이 안 된다고 나와요.

      네 편집기는 같은 사이트 주소를 쓰기 때문에 브라우저 저장 공간을 함께 나눠 씁니다. 공간이 부족하면 자동 저장이 실패할 수 있어요. 각 편집기에서 JSON으로 백업한 뒤, 이 페이지의 ‘편집기별 저장 상태’에서 다 쓴 편집기의 기록을 비우면 공간이 생깁니다.

      예시 문구는 그대로 써도 되나요?

      모든 예시 이름·가격·작업·조건은 가상입니다. 실제 정보로 바꾸고, 확인되지 않은 경력·후기·성과·할인·마감은 넣지 마세요. 판매·환불·권리 문구는 참고용이며 법률 검토를 거친 약관이 아닙니다.

      수강생에게 편집기를 공유하고 싶어요.

      각 편집기 카드의 ‘사용법’을 열고 ‘편집기 링크 복사’를 눌러 주소를 전달하면 됩니다. 누구나 로그인 없이 열 수 있고, 각자의 브라우저에 따로 저장되므로 서로의 작업이 섞이지 않습니다.

      휴대폰에서도 쓸 수 있나요?

      모든 편집기는 모바일에서도 열리지만, 사진 업로드와 긴 문구 편집은 PC가 훨씬 편합니다. 완성한 페이지는 모바일 화면을 꼭 함께 확인하세요.
