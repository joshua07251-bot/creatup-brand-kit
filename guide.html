강사·전문가·소상공인용 소개 홈페이지

시작하기

  1. 편집기를 Chrome, Edge, Safari 등 최신 브라우저에서 엽니다. 코드를 편집하거나 별도 프로그램을 설치하지 않아도 됩니다.
  2. 강사 / 전문가 / 소상공인 예시를 고릅니다. 세 예시는 서로 다른 레이아웃을 사용합니다. 업종을 선택하면 디자인과 예시 내용이 함께 바뀝니다. 업종을 바꾸면 현재 내용과 사진이 바뀌므로 먼저 백업하세요.
  3. 왼쪽 편집 패널의 01~06을 차례대로 열고 내 정보로 수정합니다.
  4. 데스크톱과 모바일 미리보기를 확인합니다. 스마트폰에서도 편집할 수 있으나 PC 사용을 권장합니다.
  5. 편집본 백업으로 JSON을, 내 홈페이지 저장으로 공개용 index.html을 저장합니다.

편집할 수 있는 것

  • 브랜드명, 직업·업종 문구, 첫 화면 제목과 소개, 문의 버튼 문구
  • 포인트 색상, 배경 색상 (밝은 배경 권장)
  • 내 사진, 사진 설명과 캡션, 소개 본문, 키워드
  • 서비스 3종, 진행 단계 3개, FAQ 3개
  • 실제 문의·예약 링크, 공개 이메일, 활동 지역, 운영 시간, 하단 정보

서비스·진행 단계의 제목이나 FAQ 질문을 비우면 해당 항목은 숨겨집니다.

연락처가 비어 있으면 문의 영역에는 미설정 안내가 표시됩니다. 가짜 문의 버튼이나 작동하지 않는 제출 폼은 넣지 않았습니다.

사진 사용

직접 촬영했거나 사용 권한을 가진 JPEG·PNG·WebP 사진을 넣으세요. 최대 10MB이며 긴 변 1,600px의 JPEG 사본을 만들어 HTML 안에 포함합니다. 원본 파일은 수정하지 않습니다. 세로형 사진이 데스크톱에 어울리며, 모바일에서는 더 가로로 잘릴 수 있으니 양쪽 화면을 확인하세요.

제공본에는 실제 인물·매장 사진을 임의로 넣지 않았습니다. 글자 그래픽은 사진 자리 표시입니다.

저장 파일의 차이

  • 편집본 JSON: 사진·문구·설정을 재편집할 때 사용합니다. 편집기의 07 · 편집본 관리에서 불러옵니다. JSON을 홈페이지로 업로드하지 마세요.
  • index.html: 편집 패널이 빠진 실제 소개 홈페이지입니다. 사진까지 포함한 단일 파일이며 외부 라이브러리·웹폰트·AI API에 의존하지 않습니다. 편집기로 다시 불러오는 파일은 아닙니다.
  • 미리보기 폴더: 세 업종의 기본 디자인을 바로 확인하는 HTML입니다. 이름과 서비스는 가상 예시이며 실제 업체나 경력에 대한 주장이 아닙니다.

브라우저 자동 저장은 보조 기능입니다. 로컬 파일 열기 방식이나 브라우저 설정에 따라 저장이 안 되거나 데이터가 지워질 수 있으므로 작업 후 JSON을 백업하세요. 파일명이나 저장 위치를 바꾸면 자동 저장 내용이 이어지지 않을 수 있습니다.

인터넷에 공개하려면

HTML 저장만으로 웹사이트가 공개되지는 않습니다. 저장한 파일을 index.html이라는 이름으로 정적 웹 호스팅에 업로드해야 합니다. 호스팅 서비스의 현재 요금·공개 범위·사용 조건을 확인하세요.

  • GitHub Pages 안내: https://docs.github.com/ko/pages/getting-started-with-github-pages/creating-a-github-pages-site
  • Netlify 수동 배포 안내: https://docs.netlify.com/deploy/create-deploys/#drag-and-drop

온라인 배포나 개인 도메인 연결은 이번 제공 파일에 포함된 실행 작업이 아닙니다. 문의·예약은 입력한 외부 서비스로 이동합니다. 회원가입, 예약 처리, 결제, 서버 저장, 관리자 시스템은 포함되어 있지 않습니다.

공개 전 마지막 점검

  • 예시 이름과 설명을 실제 정보로 바꿨습니다.
  • 예시 안내 문장과 ‘수정해 주세요’ 같은 문구를 모두 교체했습니다.
  • 확인하지 않은 경력·자격·성과·후기를 넣지 않았습니다.
  • 사진 사용 권한을 확인하고 모바일 잘림을 살펴봤습니다.
  • 실제 문의 링크 또는 이메일을 입력했습니다.
  • 저장한 index.html을 직접 열어 문구·FAQ·링크를 확인했습니다.
  • 필요한 사업자 정보·운영 정책·업종별 필수 표시 사항을 확인했습니다.
  • 공개할 수 있는 연락처만 넣었습니다.
  • JSON 편집본을 따로 보관했습니다.

이용 범위

본 템플릿으로 만든 홈페이지는 수강생 본인의 사업·활동 소개와 고객 작업에 수정해 사용할 수 있습니다. 템플릿 원본·편집기의 재배포·재판매 범위는 크리트업에서 별도로 정해 안내하세요. 넣는 사진·글·상표 등 타인의 권리는 별도로 확보해야 합니다. 웹사이트의 유입·문의·매출·검색 노출은 보장하지 않습니다.

움직임 효과

색상과 서체의 기본 방향, 공통 편집 기능과 모션을 유지하면서 업종별 배치를 다르게 구성했습니다.

  • 스크롤에 맞춘 제목·본문·카드의 순차 등장
  • 고정 반투명 메뉴와 현재 섹션 표시, 읽기 진행선
  • 마우스 위치에 반응하는 사진 기울기와 서비스 카드 하이라이트
  • 버튼의 빛 반사와 호버, 사진 주변의 선 프레임
  • 문의 영역의 장식 라인, 맨 위로 이동
  • 우측 하단 ‘움직임 켜짐/꺼짐’ 버튼

모바일·터치 환경에서는 사진 기울기와 카드 추적 효과를 사용하지 않습니다. 기기의 ‘동작 줄이기’ 설정에서는 애니메이션을 중단하고 모든 내용을 표시합니다. 스크립트를 실행할 수 없는 환경에서도 기본 내용은 보입니다. 움직임 설정은 방문 세션 동안만 유지됩니다. 미리보기와 저장한 홈페이지에 같은 효과가 적용됩니다. 정적인 스크린샷으로는 등장·호버 효과가 보이지 않으니 브라우저에서 스크롤해 확인해 주세요.

업종별 레이아웃

  • 강사형: 큰 소개 문구 + 아치형 프로필, 프로그램 카드 → 수업 진행 안내 → 강사 소개.
  • 전문가형: 좌측 사진·우측 설명의 분할 화면, 소개 → 전문 분야 목록 → 세로형 진행표.
  • 소상공인형: 넓은 사진과 겹친 소개 패널, 비대칭 서비스 카드 → 공간 소개 → 예약·이용 안내.

00_디자인비교.html에서 한눈에 비교할 수 있습니다. 미리보기 폴더의 teacher.html / expert.html / shop.html을 열면 실제 크기로 확인할 수 있습니다.

백업 파일의 업종 선택도 함께 저장·복원되며, HTML 내보내기에는 현재 선택한 업종의 레이아웃이 적용됩니다. 기존 편집본 JSON도 불러올 수 있습니다. 업종 예시 변경 시 기존 문구·사진이 바뀌므로 먼저 백업하세요.

구성과 흐름

이 상세페이지는 상단 메뉴가 없는 최대 폭 860px의 긴 세로형 상세페이지입니다. 고객의 관심·고민·제안·구체적 내용·가격과 조건이 위에서 아래로 이어집니다.

  • 상품형: 대표 사진 → 고민과 핵심 제안 → 사진별 상세 설명 → 사용 방향·관리 → 구성·규격 → 가격·구매 조건
  • 강의형: 모집 표지 → 추천 대상 → 학습 방향·결과물 → 연습과 커리큘럼 → 자료·운영 정보 → 수강료·신청 조건
  • 서비스형: 의뢰 안내 → 필요한 상황 → 납품물 설명 → 포함·제외 범위 → 진행 절차 → 견적·상담 조건

일반 홈페이지의 메뉴·소개 카드·탐색형 구조를 사용하지 않습니다. 상품 사진은 작은 썸네일 갤러리가 아니라 본문의 큰 사진으로 배치됩니다. 모바일에서는 하단 구매·신청·상담 안내로 이동하는 버튼을 제공합니다.

파일

  • index.html: 편집기
  • compare.html: 세 가지 긴 상세 흐름의 앞부분 비교
  • product.html: 상품 상세페이지
  • course.html: 강의 모집 상세페이지
  • service.html: 서비스 의뢰 상세페이지

최신 Chrome·Edge·Safari 등의 브라우저에서 편집기를 여세요. 코드를 직접 고치거나 프로그램을 설치할 필요가 없습니다.

만드는 순서

  1. 상품·강의·서비스 중 선택합니다. 디자인과 예시 문구가 함께 바뀌므로 진행 중인 작업은 먼저 백업하세요.
  2. 01에서 브랜드·판매명·첫 제목·소개를 수정합니다.
  3. 02 · 고객의 고민과 제안 흐름에서 추천 대상, 고민 제목·본문, 핵심 제안 문장, 사용 방향·학습 결과·납품물 설명을 적습니다. 막연한 소개 대신 구매 판단에 필요한 내용을 씁니다.
  4. 03~04에서 가격·별도 비용·실제 외부 링크·이메일·사진을 설정합니다.
  5. 05~09에서 핵심 설명 또는 납품물 3가지, 상세 정보 4개, 사용 단계·커리큘럼·진행 절차 4개, 구성과 제공 범위, 판매자·강사·제공자 소개를 수정합니다.
  6. 10~12에서 FAQ, 운영 정책, 문의와 하단 사업자 정보를 확인합니다.
  7. 모바일과 실제 저장 파일을 확인한 뒤, 가상 예시 안내를 해제합니다. 체크를 해제해도 본문의 가상 문구는 자동으로 바뀌지 않습니다.
  8. JSON 편집본과 index.html을 각각 저장합니다.

본문에는 편집을 돕는 가상 예시와 안내 문구가 들어 있습니다. 공개 전 ‘가상’, ‘입력하세요’, ‘수정하세요’ 등의 표현까지 검토하고 실제 내용으로 교체하세요.

사진과 내용

  • JPEG·PNG·WebP, 장당 10MB 이하 사진 3장을 넣을 수 있습니다.
  • 긴 변 최대 1,600px의 JPEG 사본을 만들어 HTML에 포함합니다. 원본 파일은 수정하지 않습니다.
  • 상품형은 대표·상세·사용 장면을 본문에 크게 배치합니다. 사진이 없으면 사진 자리 표시가 보입니다.
  • 강의형은 대표 사진을 표지 뒤, 추가 사진을 연습·커리큘럼 흐름 사이에 표시합니다. 사진을 넣지 않으면 해당 사진 영역을 생략합니다.
  • 서비스형은 대표 사진을 납품물 설명에 배치하며, 추가 사진은 진행 절차 뒤에 표시합니다. 대표 사진이 없으면 납품 예시 사진 자리 표시가 보입니다.
  • 자리 표시 그래픽은 실제 상품·실적·수업 사진이 아닙니다. 직접 촬영했거나 사용·공개 권한을 가진 자료만 넣으세요.
  • 장점·상세 정보·단계·FAQ·운영 정책 배열 항목의 제목을 비우면 그 항목이 숨겨집니다.

저장과 이전 편집본

  • JSON: 사진·선택한 유형·문구를 다시 편집하는 백업입니다. 13 · 편집본 관리에서 불러옵니다.
  • index.html: 편집 패널이 빠진 독립 상세페이지입니다. 외부 웹폰트·라이브러리·AI API 없이 열립니다. HTML을 편집기로 다시 불러오는 기능은 없으므로 JSON도 보관하세요.
  • 이전 판매 안내 페이지 편집기의 JSON도 불러올 수 있습니다. 기존 이름·가격·사진·설명 등은 유지하고, 새 고민·제안 흐름 항목은 유형별 기본 예시로 채웁니다. 새로 채워진 항목은 반드시 직접 검토하세요.
  • 소개 홈페이지 01의 JSON은 별도 형식이므로 호환되지 않습니다.
  • 자동 저장은 이 브라우저에만 남는 보조 기능입니다. 브라우저 설정·로컬 파일 열기 방식·저장 용량에 따라 실패할 수 있으니 JSON을 별도로 백업하세요.

공개와 판매 기능의 범위

이번 결과물은 상세페이지형 HTML과 편집기입니다. 쇼핑몰에 업로드할 분할 JPG·PNG 이미지나 인쇄용 PDF를 생성하는 기능은 포함하지 않습니다. HTML 파일 저장만으로 인터넷에 공개되지 않으며, 이 저장소의 index.html은 GitHub Pages에서 편집기로 공개합니다. 편집기로 생성한 개별 상세페이지를 공개하는 작업은 별도입니다.

실제 구매·수강 신청·예약·상담 서비스의 주소를 버튼에 넣어 사용합니다. 링크를 비우고 공개 이메일만 넣으면 이메일 작성 창으로 연결됩니다. 둘 다 비어 있으면 미설정 안내가 표시됩니다. 이 파일 자체에는 결제·주문·예약 처리·회원 관리·개인정보 수집·서버 저장 기능이 없습니다.

공개 전 확인

  • 가상 이름·가격·제공 내용·안내 문구를 실제 정보로 교체했습니다.

작업 추가와 정리

작업물 탭에서 최대 12개의 작업을 편집할 수 있습니다.

  1. 작업을 펼치고 제목·분야·요약·직접 맡은 역할·실제 기간·사용 도구와 형식을 적습니다.
  2. ‘출발점’에는 목적과 조건, ‘나의 접근’에는 직접 한 일과 선택한 이유, ‘결과와 확인’에는 실제 완성물과 확인 가능한 근거를 씁니다.
  3. 대표 이미지와 상세 사진 2장을 넣고 각각의 설명을 적습니다.
  4. 영상·음악·문서·사이트 등 실제 공개 작업 링크를 연결할 수 있습니다. 영상·음악 파일을 자체 업로드하거나 재생하는 기능은 포함하지 않습니다.
  5. 협업자의 역할과 자료·이미지 출처를 구분해 적습니다.
  6. ‘위로/아래로’로 순서를 바꾸거나 ‘대표로’를 눌러 가장 중요한 작업을 첫 번째에 둡니다. 삭제 시 해당 작업과 사진이 함께 지워집니다.

분야 이름이 같은 작업끼리 자동으로 필터가 만들어집니다. 같은 분야를 묶으려면 표기를 통일하세요. 예를 들어 ‘영상’과 ‘영상 제작’은 별개의 분야로 표시됩니다. 대표 작업이 현재 필터에 포함되지 않으면 그 필터에서는 일반 작업 목록만 표시됩니다.

실제 작업과 기획 예시의 구분

기본 인물과 프로젝트 4개는 모두 가상입니다. 실제 촬영·제작·납품·수업 운영 또는 성과를 입증하는 사례가 아닙니다. 배경 그래픽도 실제 결과물 사진이 아니라 텍스트 커버입니다.

직접 수행한 실제 작업으로 교체한 뒤에만 작업별 ‘가상 프로젝트 / 기획 예시 표시’를 해제하세요. 기획만 했거나 연습용으로 만든 내용은 그 범위가 드러나도록 적으세요. 조회수·매출·고객 수·성과·자격·경력은 확인할 수 있는 근거가 있을 때만 넣으세요. 협업 작업을 전부 혼자 만든 것처럼 소개하지 마세요.

이미지

  • 사진을 넣지 않아도 작업별로 고른 텍스트 커버가 표시됩니다. 대표 이미지를 넣으면 텍스트 커버 대신 그 이미지가 나타납니다.
  • 본인 소유이거나 사용·공개 권한을 확보한 자료만 넣으세요. 고객명·얼굴·상표·내부 자료·음악·화면 캡처의 공개 권한도 확인해야 합니다.

저장과 복원

  • 편집본 백업: 사진·문구·작업 순서를 담은 JSON입니다. 다시 수정하려면 ‘저장·안내’ 탭의 JSON 불러오기로 복원합니다.
